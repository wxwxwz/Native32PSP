# 游戏画面呈现与滤波

本次调整将常见画布的缩放交给 PSP GU 纹理绘制，并减少核心图像合成中的无效工作。目标是减少 CPU 缩放和逐像素判断；尚无本次改动的 PSP 真机速度结果，不能据此宣称帧率提升。

## 显示设置

设置的“显示”分类增加“滤波”：默认“清晰”（最近邻），可选“平滑”（双线性）。滤波用于实际发生缩放的画面，原尺寸显示不进行滤波。已有 `settings.txt` 中的滤波值继续保留，退出设置时保存。

“原尺寸”“保持比例”“铺满屏幕”的输出尺寸规则保留。原尺寸超过 480×272 时仍显示源画布左上部分，不改为居中裁剪。缩放采用 GPU 标准的像素中心采样；相较旧 CPU 按目标像素左边界取样的方式，部分最近邻缩放边界可能相差一个源像素。这不改变游戏逻辑、精灵位置或原生分辨率。

## 呈现路径

`src/platform/game_presentation.*` 保留一张对齐的 ABGR 画面，路径如下：

| 条件 | 准备与输出 |
| --- | --- |
| 实际发生缩放，源宽和高均不超过 512 | 转换原生画布为纹理，使用 GU 2D sprite 条带缩放，清晰/平滑对应最近邻/线性纹理采样 |
| 原尺寸，或输出尺寸与源尺寸相同 | 转换可见区域，经 GE 复制到显示页 |
| 需要缩放，源宽或高超过 512 | CPU 按所选滤波生成不超过 480×272 的输出，再经 GE 复制到显示页 |

纹理宽高取 2 的幂，行跨度至少为 16 像素；纹理地址按 16 字节对齐。非 2 的幂画布将最右一列和最下一行延伸至填充区域，配合 clamp 防止平滑滤波读出黑边。纹理按最多 32 个屏幕像素宽的条带绘制，避免一次跨越整幅纹理。

GE 复制使用独立对齐的行跨度，可见宽度无需是 16 的倍数，例如 362 像素宽的画面仍可使用 GE。提交前写回纹理数据，并写回、失效目标页的 CPU 缓存；GU 完成并同步后，CPU 才绘制 FPS 等叠加层或读取截图。

单张纹理的像素存储上限为 512×512×4，即 1 MiB，另加对齐余量；超大画布的软件缩放输出最多约 510 KiB，另加对齐余量。此处仅指呈现缓冲，不包括原生 framebuffer、资源缓存、音视频缓冲和显存。缓冲会复用容量，切换到较小画布后不保证立即归还全部内存。

## 截图与叠加层

平时只保留呈现需要的画面。请求截图时才将该画面重新绘制到当前不可见的显示页，按输出尺寸读取；这一过程不交换前后页，也不将 FPS、截图通知等叠加层写入截图。读取结果沿用当前缩放和滤波设置。

## 核心合成

`src/core/renderer.*` 在解码图像前先检查图像尺寸与画布交集，完全屏外的图像不触发像素解码。可见图像先裁剪一次，再合成有效行。

`Native32Reader` 图像缓存和自有精灵替换图像记录“所有像素 alpha 非零”的标记，满足条件的可见行直接复制。这里保持原有规则：alpha 为零的像素不覆盖目标，任何非零 alpha 的像素直接替换目标；没有新增半透明混合，也没有把 alpha 非零误当作 alpha 必须为 255。公开 `blitImage` 调用仍逐像素检查，避免外部修改像素后使用过期标记。

## 性能日志

周期日志增加 `present:` 一行：

| 字段 | 含义 |
| --- | --- |
| `prepare_us=平均/最大` | 画面准备耗时，包含颜色转换、填充，以及必要的软件缩放 |
| `transfer_us=平均/最大` | 提交呈现并等待 GU/GE 完成的耗时 |
| `mode=GU-texture` 或 `GE-copy` | 本次保留画面的呈现路径；`GE-copy` 也包含软件缩放后的复制 |
| `filter=sharp` 或 `smooth` | 当前滤波设置；原尺寸模式下不发生滤波 |
| `surface_kb` | 呈现缓冲保留容量，按 1024 字节计，不代表整机内存占用 |

评估时应同时看 `core_us`、`copy_us`、`render_period`、音频队列与欠载信息。截图的按需重绘不是普通逐帧呈现成本，主机耗时也不能换算成 PSP 帧率。

## 验证

PSPSDK 15.2.0 在全新目录全量构建通过，无编译警告；下载后的加密 PBP、模块长度、图标和 SFO 元数据校验通过。主机 AV、MP3、核心渲染回归通过，AV 与核心渲染的 ASan/UBSan 检查通过，原有核心渲染摘要仍为 `8d63a40ac08ec6b1`。

新增回归逐像素检查清晰采样及条带边界、平滑滤波（每通道误差不超过 1）、非幂次和细长画布、512 尺寸边界、超大画布回退、双显示页、内存上限与释放。应用回归检查截图保留滤波且不含 FPS/提示、不改变当前可见页，以及四行显示设置的导航与保存兼容。主机绘制预览已检查，显示分类四行没有覆盖页脚。

相关入口为 `sh tests/run-av.sh`、`sh tests/run-host.sh`、`sh tests/run-mp3.sh`，以及可选的 `SANITIZE=1 sh tests/run-av.sh`。主机接口替身可检查尺寸、地址/跨度约束、模拟采样结果、截图与设置行为；无法验证真实 GE 的缓存时序、滤波取整或吞吐。

真机需确认清晰/平滑切换、细线与条带接缝、右下边缘、超屏原尺寸裁剪、截图内容及连续运行稳定性，并结合新日志比较同一游戏与场景。当前真机效果和速度均待验证。
